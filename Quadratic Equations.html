Quadratic Equations

Defining a Quadratic Equation

  • A quadratic equation is an equation with the form ax2 + bx + c = 0 (standard form)
  • It is an equation which has a degree of 2, or 2 as the highest exponent
  • a, b, and c are all real numbers, and a should not be equal to 0

First Method: Extracting the Square Root (Easiest Method)

  • This method is basically what it's called, you extract the square root from both sides of an equation using the square root property
  • Ex. of an equation 3x2 - 3 = 24

Solving:

  1. 3x2 - 3 = 24 (Given)
  2. 3x2 - 3 + 3 = 24 + 3 (Applying Addition Property of Equality)
  3. 3x2 = 27 (Simplification)
  4. 3x2/3 = 27/3 (Division Property of Equality)
  5. x2 = 9 (Simplification)
  6. √x2 = ±√9 (Square Root Property/Extracting the Square Root)
  7. x = ±3 (Simplification and Final Answer)

Second Method: Factoring

  • Uses the Zero Product Property, which states that if ab = 0, then either a = 0 or b = 0
  • Involves Common Monomial Factoring and the factoring of Perfect Square Trinomials
  • Ex. of equations 3x2 + 18x = 0, x2 + 10x - 11 = 0

Solving:

  • 3x2 + 18x = 0
  1. 3x(x + 6) = 0 (CMF)
  2. 3x = 0| x + 6 = 0 (Zero Product Property)
  3. 3x/3 = 0/3| x + 6 - 6 = 0 - 6
  4. x = 0| x = -6
  5. Roots: x = 0, -6

  • x2 + 10x - 11 = 0
  1. x2 + 10x - 11 = 0 (Think of 2 numbers that when added is equal to the middle term B, but when multiplied is equal to the last term C)
  2. (x + 11) (x - 1) = 0
  3. x + 11 = 0 | x - 1 = 0 (Zero Product Property)
  4. x + 11 - 11 = 0 - 11 | x - 1 + 1 = 0 + 1
  5. x = -11 | x = 1
  6. Roots: x = 1, -11
(You may check your answers/roots through substitution)

Third Method: Completing the Square (Intimidating for some, but it's easy)

  • As stated by the name, this method involves completing an actual square.
  • This method involves using the expression (b2)2 (Addition Property of Equality is paired with it), which serves as your c in your Perfect Square Trinomial (PST)
  • Ex. 3x2 + 9x + 6 = 0

Solving:

  1. 3(x2 + 3x + 2) = 0 (CMF)
  2. 3/3 (x2 + 3x + 2) = 0/3 (Division Property of Equality)
  3. x2 + 3x + 2 = 0 (Simplification)
  4. x2 + 3x + 2 - 2 = 0 - 2 (Subtraction Property of Equality)
  5. x2 + 3x = -2 (Simplification)
  6. x2 + 3x + (32)2 = -2 + (32)2 (Completing the Square)

  7. x2 + 3x + 94 = -2 + 94 (Simplification A)

  8. (x + 32)2 = - 84 + 94 (Simplification B)

  9. (x + 32)2 = 14 (Simplification C)

  10. √(x + 3/2)2 = ±√1/4 (Extracting the Square Root)
  11. x + 3/2 = ±1/2 (Simplification)
  12. x + 3/2 - 3/2 = -3/2 ±1/2 (Subtraction Property of Equality)
  13. x = -3/2 ±1/2 (Simplification)
  14. x = -3/2 + 1/2| x = -3/2 - 1/2
  15. Roots: x = -1, -2

Fourth Method: Use of the Quadratic Formula (Universal Reliability)

  • Formula: x = -b ± √b2 - 4ac / 2a
  • Requires you to find the a, b, and c values
  • Ex. 3x2 - 9x + 3 = 0
  1. a = 3, b = -9, c = 3
  2. x = -(-9) ± √(-9)2 - 4(3)(3) / 2(3)
  3. x = 9 ± √81 - 36 / 6
  4. x = 9 ± √45 / 6
  5. x = 9 + √45 / 6, x = 9 - √45 / 6
(Note: You can simplify the roots further to get 3 + √5 / 2, 3 - √5 / 2)
