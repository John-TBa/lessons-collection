Quadratic Functions

Part 1: Introduction

What is a Quadratic Function?

  • A quadratic function is a function in the second degree where "a" should not be equal to 0.
  • Standard form is represented as f (x) = ax2 + bx + c or y = ax2 + bx + c

Identifying Quadratic Functions Along With Your a, b, and c Values:

  • y = 10x2
    • a = 10, b = 0, c = 0

  • y - 10 + 3x = 3x2
    • y = 3x2 - 3x + 10
    • a = 3, b = -3, c = 10
