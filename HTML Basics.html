Introduction to HTML

What is HTML?

HTML, also known as Hypertext Markup Language, is a standard markup language used in creating and structuring webpages. It acts as a foundation or skeletal structure; without HTML, websites cannot exist.

What does HTML Do?

It tells the browser:

  • What content to display
  • Where to display the content
  • How the content is organized

Markup Language Vs. Programming Language

  • Markup Language is used for structuring websites, while programming language gives a set of instructions to a system.

Hypertext

- is clickable text that contains links connecting one webpage to another.

  • Website = A collection of webpages (Like a Full Book)
  • Webpage = A single page of a website that displays information
  • Hyperlinks = The actual links contained in hypertext which is used to reach other webpages within a website

Basic structure of a website

Functions of each tag:

  1. DOCTYPE tag - declares the file as HTML 5 (Not Required if File is already HTML File)
  2. html tag - root element
  3. head tag - stores webpage information
  4. title tag - displays title on browser tab
  5. body tag - contains everything seen on the webpage
  • Opening tag = < >
  • Closing tag = < / >
