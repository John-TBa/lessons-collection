Equations Transformable into Quadratic Equations

Part 1: Transforming Simple Equations into Quadratic Equations

  • Let's say you are trying to build a rectangular structure. The required area of said structure is 120 square meters. The relationship of the dimensions is that the length is 4 meters longer than the width, now, you have to find the measurements.
  1. Given: A = 120, l = x + 4, w = x
  2. Structure/Geometric Figure: Rectangle
  3. Formula: l x w = A
  4. Substitution: x(x + 4) = 120
  • Now you have the equation x(x + 4) = 120, but it is still not a quadratic equation. We need to fix that.
  1. x(x + 4) = 120 (Given)
  2. x (x) + x (4) = 120 (Distributive Property of Equality)
  3. x2 + 4x = 120 (Simplification)
  4. x2 + 4x - 120 = 120 - 120 (Subtraction Property of Equality)
  5. x2 + 4x - 120 = 0 (Simplification)
  • Now you have the actual quadratic equation x2 + 4x - 120 = 0, you can finally solve it normally.
  1. x2 + 4x - 120 = 0
  2. x2 + 4x + 4 = 120 + 4

  4. x + 2 = ±√124
  5. x = -2 ± √124

  • Your width is = -2 + √124
  • Your length = -2 + √124 + 4, which can be simplified into 2 + √124

  • l = 2 + √124, w = -2 + √124 (We do not use the negative value of x for obvious reasons)
