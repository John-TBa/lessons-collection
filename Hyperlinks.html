Creating Hyperlinks

What is a Hyperlink?

  • A hyperlink is a link that is contained within hypertext which connects one webpage to another
  • It is used for website navigation
  • Contained in an opening anchor tag

(For the sake of functionality and demonstration, angled brackets will be replaced with parentheses)

What do the attributes do?

  1. href - contains the actual URL of the destination webpage
  2. target - tells the browser to either open the new webpage on the same tab (_self which is the default one), or on a new tab (_blank)
  3. title - shows text when a cursor is hovered over the hyperlinl
  4. The actual text (In between the opening and closing a tags) - Hypertext
