Image Insertion

General Overview:

There are basically 2 types of image insertion in HTML. There is the insertion via an online image's link, and there is an insertion via a downloaded image.

Take Note:

  • The download method only shows the image on that same device that you have that file on. This is because it is saved locally.
  • The link method shows your image on any device as that image is already uploaded on the internet.

Steps in Inserting an Image Via Link:

  1. Type in the (img src="__") tag in your coding application (Take note that the parentheses that I used are just placeholders for the angled brackets)
  2. Open your web browser and find the image you want to insert in your webpage
  3. Right click the image then copy the image link
  4. Paste your image link in between the quotation marks in your img src tag
  5. Close the img src tag if you haven't already (It is a self-closing tag, so no need for an actual closing tag)

Steps in Inserting an Image Via Download:

  1. Type in the (img src="__") tag in your coding application (Take note that the parentheses that I used are just placeholders for the angled brackets)
  2. Open your web browser and find the image you want to insert in your webpage
  3. Right click the image then download the image
  4. Once you have downloaded it, find your image in your file explorer
  5. After locating your image, right click it and click on properties
  6. Inside the properties window, locate the location of the image file and copy it
  7. Paste your image location in between the quotation marks in your img src tag
  8. After pasting it in, use a backslash (\) and type in the name and file path of your image (ex. egg.jpg)
  9. Close the img src tag if you haven't already
